# Security Policy

We take security seriously. Please read the instructions below to report security vulnerabilities or concerns.

## Reporting a Vulnerability

**Please do not report security vulnerabilities publicly through GitHub issues.** 

Instead, please use the repository's private security reporting mechanism on GitHub:
1. Navigate to the **Security** tab of the repository.
2. Under **Advisories**, click **Report a vulnerability**.

*Placeholder: If private security reporting is not available, please contact the maintainer directly at the email/contact configured in the project settings.*

## Guidelines

* **No Credentials**: Do not include any credentials, API keys, passwords, or tokens in issues, PRs, or documentation.
* **Keep Private**: Keep details of any security vulnerability private until a fix has been released and a public announcement has been coordinated.
